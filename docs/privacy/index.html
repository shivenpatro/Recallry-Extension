Privacy Policy

Effective date: August 30, 2026

Recallry is a local-first Chrome and Edge extension for saving and organizing user-selected website references. It does not require an account or operate developer-controlled analytics, advertising, synchronization, or data-collection services in the current release.

Single Purpose

Recallry helps users explicitly save, organize, search, protect, back up, and revisit website references as private visual collections.

Information Recallry Processes

  • Page URL, title, domain, favicon, and available preview image for pages the user explicitly saves.
  • Notes, tags, labels, collection names, and other content entered by the user.
  • Save date, ordering, archive state, Trash state, optional script-free snapshots, local backups, imports, exports, and Vault settings.
  • A Vault master password and optional recovery answer while deriving local cryptographic keys. Recallry does not store those raw secrets; it stores password-derived verifiers and wrapped encryption keys locally.
  • Link-health and HTTP response status when the user explicitly starts a scan.

Recallry does not read or retain general browsing history. It processes only pages and saved domains involved in a user-requested Recallry action.

Storage and Data Transfers

Recallry stores data in the browser profile using IndexedDB and Chrome's memory-backed extension session storage. It does not transmit this information to the developer.

Opening a saved link contacts that site. Uncached favicon or preview images may be requested from their source. An on-demand link-health scan contacts only saved origins for which the user granted optional access.

Recallry includes no analytics, advertising, tracking pixels, or remote executable code and does not sell user data.

Chrome Web Store Limited Use

Recallry's use of information received from Chrome APIs is limited to providing and improving its user-facing save, organization, search, backup, Vault, snapshot, and link-health features.

Recallry does not use or transfer this information for personalized advertising, creditworthiness, lending, or unrelated purposes. It does not permit humans to read user data except with explicit user consent for support, when required for security or legal compliance, or after aggregation and anonymization for internal operations. The current release does not transmit user data to the developer or third parties.

Recallry's use and transfer of information received from Chrome APIs adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements.

Permissions

  • activeTab: temporary current-page access after the user invokes Recallry.
  • scripting: page metadata capture during that explicit action; no script runs continuously.
  • contextMenus: browser-menu save destinations.
  • storage: temporary trusted Vault session coordination.
  • alarms: local rolling recovery-point scheduling.
  • Optional HTTP(S) access: exact saved origins included in a user-started link-health scan. Users can deny or remove access.

Vault and Offline Snapshots

Vault Mode encrypts protected links and collection metadata locally with AES-GCM. New password and recovery verification uses PBKDF2-SHA-256. Ordinary collections and exported files are not automatically encrypted.

Optional snapshots remove scripts, forms, frames, embedded media, external styles, tracking-capable resources, and unsafe URL schemes. They open in a sandboxed extension reader with network loading disabled and are Vault-encrypted when stored in a protected collection.

Retention and User Control

  • Deleted items remain in Trash until restored or permanently deleted.
  • Up to five rolling recovery points remain local.
  • Users can remove saved-site permissions, export data, permanently delete data, clear storage, or uninstall Recallry.

Exported files are controlled by the user and should be treated as sensitive.

Children

Recallry is a general productivity tool and is not directed to children under 13.
