# Security Policy

## Reporting a Vulnerability

Please do not publish suspected security issues in a public GitHub issue. Contact the repository owner privately through the GitHub profile associated with this project and include:

- A short description of the issue.
- Reproduction steps or a proof of concept.
- The affected browser and extension version.
- Any suggested mitigation.

Please do not include real passwords, recovery answers, private browsing data, or exported Linkscape backups in a report.

## Scope

Security reports are especially valuable for:

- Vault key handling and encryption boundaries.
- Data leakage through permissions, remote requests, or logs.
- Import/restore data validation.
- Cross-collection movement of protected links.
- Manifest V3 service-worker message handling.
